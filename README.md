# 本地围棋记谱工具

一个纯前端、离线可用的围棋记谱网页工具，用于本地复盘、现场摆棋讨论、记录每一步备注，并与 SGF 工具链互通。

## 1. 项目用途

- 19×19 围棋摆棋与复盘。
- 每一步绑定评论（中文可用）。
- 导入 / 导出 SGF，便于后续在 KaTrain、KataGo 等软件继续复盘。
- 刷新页面后自动恢复当前棋谱（`localStorage`）。

## 2. 如何运行

本项目无后端、无数据库、无依赖安装。

### 方式 A（推荐）

直接双击打开 `index.html`（桌面浏览器）。

### 方式 B（可选）

如果你习惯本地静态服务器，也可在项目目录运行任意静态服务再访问页面。

## 3. 当前支持的功能

- 标准 19×19 棋盘、九个星位。
- 棋盘四边显示坐标：横向 A–T（跳过 I），纵向从下到上 1–19，左下角为 A1。
- 点击交叉点落子，黑白自动轮流。
- 鼠标悬停在空交叉点时，显示当前行棋方颜色的小方块预览；移出落子范围或棋盘时消失。
- 禁止重复落子。
- 自动提子。
- 禁止明显自杀棋。
- 基本打劫判断：禁止立即还原到上一盘面。
- 棋谱导航：上一手、下一手、回到第一手、跳到最后一手、Undo、Redo。
- 当前手备注：切换手数时自动读取对应 comment，编辑即保存。
- SGF 导出：包含 `GM[1] FF[4] SZ[19]`、落子、每手 `C[...]`。
- 导出时自定义文件名：点击“导出 SGF”后输入名称，支持中文和空格；省略 `.sgf` 时自动补全，已有 `.sgf` 扩展名不会重复添加。不修改名称即可使用默认时间戳名称，点击“取消”则不下载。空名称、非法字符和 Windows 保留名称会提示重新输入。
- SGF 导入：读取主变化（单一路径），恢复落子与备注。
- 本地自动保存：`moves`、`comments`、`currentMove`。
- 新建棋局（清空当前记录）。

## 4. 当前不支持的功能

- 目数计算、胜负判定、贴目。
- 超级劫与完整比赛规则细节。
- 完整 SGF variation tree 编辑（仅主变化）。
- AI 复盘、联网、账号、后端、数据库、云同步。

## 5. 后续可扩展方向

- 变化分支树（variation）可视化与编辑。
- 棋盘标记工具（三角、方块、字母、圈点等）。
- 对局元数据编辑（黑白姓名、日期、赛事、贴目）并写入 SGF。


应用运行不需要安装依赖。安装 Node.js 后，可在项目目录运行导出功能回归测试：

```sh
node --test tests/export.test.cjs
```
